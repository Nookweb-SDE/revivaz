# Revivaz: condomínio primeiro · marca global isolada

**Contexto local (Taboão da Serra):** em menos de 1 ano, duas pessoas do prédio tiraram a própria vida. O **Revivaz** neste workspace existe para **ajudar quem está aqui dentro primeiro** — vizinhos, síndico, porteiros, famílias — com acolhimento 24/7, triagem e caminho até humano / **CVV 188** / **SAMU 192**.

**Ambiente:** apenas **DEV** neste workspace (`NODE_ENV=development`). Produção na VPS não é o alvo desta fase de validação no condomínio.

**Arquitetura de marca (dois produtos, um DNA):**

| Camada | Nome | Escopo | Repo / deploy |
|--------|------|--------|----------------|
| **Âncora** | **Revivaz** | Condomínio + Taboão da Serra | Este repo (`IZAI-SDE/revivaz`) · só `npm run dev` / `dev:api` |
| **Expansão** | **Nome a escolher** (lista abaixo) | Municípios → Brasil → mundo | **Fork/repo novo**, branding, domínio e env **isolados** — sem misturar com o condomínio |

Princípio: validar cuidado no prédio → copiar o código para outro nome → crescer sem diluir o propósito local.

Em crise: **CVV 188** (24h) · **SAMU 192** · CAPS do município.
